Website & Media Pembelajaran WebAR Garuda Pancasila

Dokumen penjelasan lengkap mengenai tujuan proyek, pengertian teknologi, cara pembuatan, alur kerja, panduan penggunaan, serta pemecahan masalah teknis pada website SDN Pakis V/372 Surabaya.

Nama Proyek Web & Media AR SDN Pakis V
Materi Edukasi Pendidikan Pancasila (Fase B/SD)
Inovasi Utama Web Augmented Reality (WebAR)

1 Ringkasan Proyek & Tujuan Pembuatan Media

Apa Sebenarnya Proyek Ini?

Proyek ini merupakan pembuatan Website Resmi Profil SDN Pakis V Surabaya yang di dalamnya diintegrasikan sebuah modul inovasi khusus berupa Media Pembelajaran Interaktif Berbasis WebAR (Web Augmented Reality) dengan tema Lambang Negara Garuda Pancasila.

🎯 Latar Belakang & Masalah Nyata:

Selama ini pembelajaran materi lambang negara di Sekolah Dasar umumnya menggunakan gambar dua dimensi (2D) di buku paket atau poster dinding kelas yang bersifat pasif. Menurut psikologi perkembangan anak, siswa usia sekolah dasar (7–12 tahun) berada pada tahap operasional konkret. Mereka membutuhkan alat peraga nyata dan interaktif agar materi tidak abstrak dan lebih cepat dipahami.

Solusi yang dihadirkan di website ini: Website ini menghadirkan replika patung 3D Garuda Pancasila yang dapat diputar 360 derajat, dilengkapi pembaca suara otomatis, serta dapat dimunculkan langsung ke dunia nyata melalui kamera HP atau laptop siswa tanpa perlu mengunduh aplikasi dari PlayStore/AppStore.

2 Pengertian Teknologi yang Ada di Dalam Website

Semua teknologi yang dipilih untuk proyek ini dirancang agar ringan, ramah anak, dan 100% gratis tanpa biaya langganan. Berikut penjelasan fungsi masing-masing teknologi dalam bahasa sederhana:

A. Teknologi Tampilan Website

Website Berbasis Web (Bukan Aplikasi Unduhan) Arsitektur

Pengertian: Media ini adalah website online yang dibuka langsung melalui aplikasi penjelajah internet (Google Chrome, Safari, atau Microsoft Edge) menggunakan alamat URL.
Fungsi: Siswa dan guru tidak perlu mengunduh (*install*) aplikasi berat berukuran ratusan Megabyte yang sering ditolak karena memori HP penuh. Cukup klik link, website langsung dapat digunakan.

React Pondasi Pemrograman

Pengertian: Teknologi penyusun tampilan web modern buatan Meta (Facebook) yang bekerja dengan konsep menyusun balok lego mandiri (disebut komponen).
Fungsi: Halaman web dipecah menjadi beberapa bagian terpisah, seperti balok Profil Sekolah, balok Berita, balok Kamera AR, dan balok Kuis. Jika ada teks yang perlu diperbarui, kita cukup mengubah komponen tersebut tanpa mengganggu bagian web yang lain.

Vite Mesin Perakit Kilat

Pengertian: Alat perakit dan pengemas (*bundler*) kode program modern yang bertugas merapikan dan memampatkan seluruh file web sebelum dipublikasikan ke internet.
Fungsi: Menjamin website terbuka dalam hitungan milidetik sehingga tidak lemot saat diakses melalui smartphone dengan koneksi internet terbatas.

Tailwind CSS Perias Desain & Tata Letak

Pengertian: Sistem penataan gaya (*styling*) tampilan web yang mengatur tata letak, warna, ukuran tulisan, dan animasi.
Fungsi: Menjadikan website bersifat responsif (tampilan otomatis menyesuaikan layar komputer, tablet, maupun HP). Tombol-tombol dibuat besar dan berwarna kontras agar nyaman disentuh jari anak-anak.

B. Teknologi 3D & Augmented Reality (AR)

Model 3D Format .GLB (Patung Digital Garuda) Aset 3D

Pengertian: Berkas (*file*) patung digital 3 dimensi. Format .glb adalah format standar internasional untuk objek 3D di internet (seperti format MP3 untuk musik atau MP4 untuk video).
Fungsi: Objek Garuda memiliki ruang nyata (panjang, lebar, tebal, sudut 360 derajat), lengkap dengan perisai 5 sila dan pita Bhinneka Tunggal Ika. Ukuran filenya sudah dioptimalkan sangat ringan (hanya ~580 KB) sehingga hemat kuota internet siswa.

Three.js & Google Model-Viewer Mesin Penampil 3D

Pengertian: Perangkat lunak penampil objek 3D di halaman web yang dikembangkan oleh Google dan komunitas web global.
Fungsi: Memungkinkan browser Google Chrome di HP maupun laptop untuk memutar, memperbesar (*zoom*), dan menggerakkan patung Garuda 3D secara mulus tanpa memerlukan perangkat komputer yang mahal.

WebAR (Web Augmented Reality) Inti Inovasi

Pengertian: Teknologi yang memadukan dunia maya dengan dunia nyata melalui rekaman kamera HP secara langsung lewat browser web.
Fungsi: Memproyeksikan lambang Garuda ke atas meja kelas atau lantai ruangan belajar anak secara langsung, membuat pengalaman belajar menjadi sangat konkret dan interaktif.

Akses Kamera Web (`getUserMedia`) Sensor Kamera

Pengertian: Fitur izin kamera resmi dan aman yang ada di dalam browser web.
Fungsi: Membuka kamera HP/laptop siswa saat tombol *"Nyalakan Kamera AR"* ditekan. Video kamera hanya diproses secara lokal di perangkat siswa (tidak ada video yang dikirim ke internet), sehingga 100% aman bagi privasi anak.

C. Fitur Edukasi & Server Hosting

Web Speech API (Text-to-Speech / Suara Otomatis) Audio Edukasi

Pengertian: Fitur pintar yang otomatis membaca teks materi menjadi suara manusia asli berbahasa Indonesia.
Fungsi: Saat siswa mengklik lambang sila, website membacakan makna sila dan contoh perilakunya dengan suara wanita yang ramah. Membantu siswa kelas rendah yang belum lancar membaca (gaya belajar auditori).

GitHub & Netlify Cloud Hosting Server & Publikasi

GitHub: Gudang penyimpanan kode proyek yang aman di internet.
Netlify: Server cloud yang menyiarkan website selama 24 jam sehari dengan alamat resmi berkeamanan gembok hijau (HTTPS). Seluruh infrastruktur ini menggunakan paket gratis selamanya (Rp 0), tanpa ada biaya langganan bulanan bagi sekolah.

3 Bagaimana Sebenarnya Web & AR Ini Dibuat?

Berikut adalah penjelasan nyata mengenai bagaimana website dan fitur AR ini dirakit dari awal sampai selesai:

Tahap 1: Penyusunan Materi & Konten Kurikulum

Materi disesuaikan dengan Capaian Pembelajaran Pendidikan Pancasila Fase B (Kelas 4 SD) dalam Kurikulum Merdeka. Materi dirangkum menjadi 5 sila (makna perisai dan contoh perilaku sehari-hari di sekolah), rahasia filosofi bulu Garuda (17 sayap, 8 ekor, 19 pangkal ekor, 45 leher), serta 4 soal kuis evaluasi pemahaman anak.

Tahap 2: Pengolahan Aset Model 3D Garuda

Lambang Garuda Pancasila diolah menjadi model patung 3D digital berformat .glb. Warna emas, perisai lambang, dan pita Bhinneka Tunggal Ika disesuaikan agar proporsional. File 3D dikompresi hingga ukurannya hanya ~580 KB agar ringan dimuat. Dibuat pula gambar transparan resolusi tinggi (PNG) untuk kebutuhan kamera interaktif.

Tahap 3: Pembuatan Halaman Website (Frontend)

Kerangka website dibangun menggunakan React dan Vite. Tampilan diatur menggunakan Tailwind CSS dengan kombinasi warna Biru Resmi (*Navy Blue*) dan Emas Kenegaraan (*Golden Amber*). Seluruh halaman utama disusun: Beranda, Profil SDN Pakis V, Visi & Misi, Fasilitas, Tenaga Pendidik, Berita Sekolah, Prestasi, Ekstrakurikuler, dan bagian khusus Media AR.

Tahap 4: Pemrograman 4 Fitur Pembelajaran AR

Bagian Media AR dirancang dengan 4 mode belajar:

  • Mode 1 (Eksplorasi 3D & Suara): Memasang patung 3D yang bisa diputar 360°, tab 5 sila, tab anatomi 17-8-1945, dan tombol pemutar suara narasi bahasa Indonesia.
  • Mode 2 (Kamera WebAR Interaktif): Mengaktifkan kamera video perangkat secara langsung, meletakkan lambang Garuda di atas layar, menyediakan fitur geser (*drag*), slider pengatur ukuran, slider rotasi derajat, tombol efek cahaya, dan tombol jepret foto langsung unduh.
  • Mode 3 (Patung 3D Nyata di Ruangan): Menggunakan komponen Google Model-Viewer untuk memproyeksikan patung 3D berdiri di lantai atau meja kelas nyata melalui smartphone.
  • Mode 4 (Kuis Pendidikan Pancasila): Membuat kuis 4 soal interaktif dengan umpan balik benar/salah instan, penjelasan materi, dan penghitungan skor akhir otomatis.

Tahap 5: Pengujian Perangkat (Testing)

Website diuji di laptop (Chrome, Safari, Edge) serta di berbagai tipe smartphone Android dan iPhone. Memastikan kamera menyala dengan lancar, teks dapat terbaca jelas dengan kontras warna yang tinggi, serta tombol mudah disentuh oleh jari anak-anak.

Tahap 6: Publikasi Online (Deployment)

File proyek diunggah ke repositori GitHub dan dihubungkan ke server cloud Netlify. Dalam beberapa menit, website sudah dapat diakses online oleh siapa saja di seluruh dunia secara gratis dan aman (HTTPS).

5 Panduan Lengkap Penggunaan Fitur AR (Untuk Guru & Siswa)

Berikut adalah panduan operasional langkah demi langkah saat menggunakan menu Media AR di dalam proses pembelajaran:

Mode 1: Eksplorasi 3D & Suara

Tujuan: Mempelajari bentuk fisik patung Garuda secara menyeluruh dan mendengarkan penjelasan audio.

  • Buka menu "Media AR" lalu pilih tab "Eksplorasi 3D & Suara".
  • Gunakan jari di layar HP (atau kursor mouse di laptop) untuk memutar patung Garuda ke segala arah (360 derajat). Cubit layar dengan 2 jari untuk memperbesar objek.
  • Klik salah satu dari 5 lambang sila di bawah patung (Bintang, Rantai, Beringin, Banteng, Padi & Kapas).
  • Klik tombol speaker "Dengarkan Narasi Suara" agar website membacakan arti lambang dan contoh perilakunya secara otomatis.
  • Klik tab "Anatomi 17-8-1945" untuk melihat penjelasan jumlah bulu kemerdekaan pada sayap, ekor, dan leher Garuda.

Mode 2: Kamera WebAR Interaktif

Tujuan: Memproyeksikan lambang Garuda di atas meja belajar menggunakan kamera dan mengambil foto hasil belajar.

  • Pilih tab "Kamera WebAR Interaktif" lalu klik tombol emas "Nyalakan Kamera AR".
  • Ketika muncul pertanyaan izin di browser, klik "Izinkan" (Allow). Kamera HP atau webcam laptop akan menyala.
  • Arahkan kamera ke meja belajar atau lantai kelas.
  • Lambang Garuda akan tampil melayang di layar:
    • Geser posisi: Sentuh dan geser lambang Garuda ke area meja yang diinginkan.
    • Atur ukuran: Geser slider ukuran untuk membesarkan atau mengecilkan lambang.
    • Atur rotasi: Geser slider derajat rotasi untuk memutar posisi lambang.
    • Efek cahaya: Centang opsi efek cahaya emas agar lambang berpendar cerah.
  • Klik tombol hijau "Foto Bersama AR" untuk menjepret gambar. Hasil foto akan langsung terunduh ke galeri HP/laptop.
  • Jika perangkat tidak memiliki kamera, siswa dapat menekan tombol "Gunakan Simulasi Meja" untuk tetap belajar dengan meja virtual.

Mode 3: 3D Nyata di Ruangan (Native AR HP)

Tujuan: Menampilkan patung Garuda 3D berdiri di lantai atau meja kelas menggunakan sensor AR smartphone.

  • Buka website di smartphone (siswa dapat memindai Kode QR yang ada di layar laptop guru untuk membuka tautan secara instan).
  • Pilih tab "3D Nyata di Ruangan" lalu klik tombol "📱 Tampilkan AR di Ruangan Nyata".
  • Kamera HP akan membuka tampilan AR Google/Apple:
    • Arahkan kamera HP ke lantai atau permukaan meja yang terang dan datar.
    • Gerakkan HP perlahan memutar agar sensor mengenali permukaan meja.
    • Patung 3D Garuda berukuran nyata akan muncul berdiri di atas meja kelas.
    • Siswa dapat berjalan mengelilingi meja untuk melihat patung Garuda dari depan, samping, dan belakang seolah-olah patung tersebut ada di kelas.

Mode 4: Kuis Pendidikan Pancasila

Tujuan: Menguji pemahaman materi siswa dengan hasil evaluasi langsung.

  • Pilih tab "Kuis Pendidikan Pancasila".
  • Baca pertanyaan dan pilih salah satu opsi jawaban (A, B, C, atau D).
  • Website akan langsung memberi warna hijau jika jawaban benar atau merah jika salah, lengkap dengan Kotak Penjelasan Guru yang menerangkan alasan jawaban tersebut.
  • Setelah menyelesaikan 4 soal, kartu nilai akan muncul menampilkan skor perolehan siswa (skala 0–100) dan tombol untuk mengulangi kuis jika diperlukan.

6 Tanya-Jawab Teknis Populer (FAQ & Troubleshooting)

❓ Bagaimana jika kamera HP tidak mau menyala saat tombol diklik?
Penyebab: Biasanya pengguna tidak sengaja menekan tombol "Blokir" saat browser meminta izin kamera, atau izin kamera di aplikasi Google Chrome HP belum diaktifkan.
Solusi: Di browser HP (Google Chrome), klik ikon pengaturan di sebelah kiri alamat web, pilih Izin (Permissions) → Kamera (Camera), lalu ubah statusnya menjadi Izinkan (Allow). Setelah itu muat ulang (*refresh*) halaman web.
❓ Apakah media ini bisa digunakan di HP lama yang tidak memiliki sensor AR canggih?
Sangat bisa. Inilah alasan mengapa media ini dibagi menjadi 4 mode belajar. Jika HP siswa belum mendukung sensor AR canggih (Mode 3), siswa tetap dapat belajar dengan lancar menggunakan Mode 1 (Eksplorasi 3D & Suara) dan Mode 2 (Kamera WebAR Interaktif) yang kompatibel dengan 99% semua jenis smartphone berlayar sentuh. Bahkan jika tidak ada HP sama sekali, guru dapat menampilkannya di laptop dan proyektor kelas.
❓ Apakah website ini boros kuota internet?
Tidak boros sama sekali. Seluruh berkas gambar dan model 3D di website ini telah dikompresi hingga berukuran sangat kecil. Model 3D Garuda hanya berukuran ~580 KB (kurang dari 1 MB), jauh lebih ringan dibanding membuka satu postingan foto di media sosial Instagram. Setelah dibuka sekali, website tersimpan di memori (*cache*) perangkat sehingga pembukaan berikutnya jauh lebih cepat.
❓ Apakah sekolah atau pengelola website perlu membayar biaya bulanan?
Tidak ada biaya sama sekali (100% Gratis Seumur Hidup). Server hosting menggunakan paket gratis Netlify, kode tersimpan gratis di GitHub, dan suara narasi menggunakan Web Speech bawaan sistem operasi tanpa melibatkan API berbayar dari pihak luar.

Website dan Media Pembelajaran WebAR SDN Pakis V ini berhasil memadukan teknologi modern (React, Model 3D, WebAR, Text-to-Speech) ke dalam balutan media edukasi yang sederhana, mudah dipahami anak sekolah dasar, mudah digunakan oleh guru di kelas, serta tidak membebani anggaran sekolah.
